## AutoHunter AI v1.0.0 🚀
### Autonomous Global Freelance Job Hunter, Anti-Scam Shield & Deal Closer

We are excited to announce the first official release of **AutoHunter AI**!

### 🌟 Key Highlights:
- **Global High-Paying Gigs**: Live radar tracking freelance opportunities across US, UK, Europe, and Global Remote markets in USD ($), GBP (£), and EUR (€).
- **🛡️ Anti-Scam Shield & Reply Bot**: Scans incoming client emails, flags scam indicators (Telegram diversions, unpaid code requests), and drafts safe counter-replies enforcing 50% milestone deposits and watermarked demos.
- **⚡ "No Resume / No Bidding" Filter**: Direct-to-deal outreach targeting gigs with zero resume requirements or bidding wars.
- **🎯 5-15 Min AI Micro-Gigs**: Instant fulfillment categories for Video Captions & Subtitles (`.srt`/`.vtt`), Language Translations, Excel Data Cleaning, and Logo Design.
- **📦 1-Click Sanitized Deliverable Packager**: Builds working client scripts, removes personal paths, and generates a client-ready ZIP.
- **🚀 Automated Python Installer for Windows**: `run.bat` automatically detects and installs Python silently if missing!
